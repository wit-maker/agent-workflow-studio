## 2. WorkflowDocument

WorkflowDocument は、画面表示用データではなく、保存・復元・実行・監査・テンプレ化の中心である。

最低限持つ情報:

- schemaVersion
- workflowId
- title
- nodes
- edges
- viewport
- runConfig
- templates
- metadata
