# Agent Workflow Studio 機能仕様書 完全版

## 1. 基本レイアウト

```text
Top Bar: Project / Save / Run / Stop / Validate / Status
Left Sidebar: Parts / Templates
Main Canvas: Nodes / Edges / HUD / Layers
Right Inspector: Config / I/O / Test
Bottom: Metrics / Timeline / Queue / Logs / Output Preview
```

## 2. 主要画面

| ID | 画面名 | 目的 |
|---|---|---|
| UI-01 | 全体俯瞰 / メインキャンバス | ワークフロー全体の作成・確認・実行 |
| UI-02 | 全部品ライブラリ | 部品検索、確認、キャンバス追加 |
| UI-03 | 入力・収集 | 入力ソース、取得設定、正規化状況を管理 |
| UI-04 | 処理・制御フロー | 前処理、分岐、並列、リトライを設計 |
| UI-05 | 成果物ステージ | 出力、プレビュー、承認、保存を管理 |
| UI-06 | 部品設定・ブロック編集 | 個別ノードの詳細設定・テスト実行 |
| UI-07 | 外部接続・AI連携 | 外部サービス、AI、Credential、接続状態を管理 |
| UI-08 | 観測メーター・実行監視 | 実行中ジョブのログ・メトリクスを監視 |
| UI-09 | 回収・評価・再作成 | 評価、レビュー、差分、再作成を管理 |
| UI-10 | 一周後の強化状態 | テンプレ、レシピ、ナレッジ、改善提案を管理 |
| UI-11 | 認知HUD設定 | 表示優先度、危険度、通知、奥行き、折りたたみルールを管理 |
| UI-12 | 実行履歴・監査ログ | 過去実行、差分、再現、監査、エクスポートを管理 |
