# Agent Workflow Studio 要件定義書 完全版

## 1. 基本要件

Agent Workflow Studio は、AIワークフローをノードとして設計・実行・観測・検査・改善・再利用するためのローカル優先アプリである。

単なるチャットUI、単なるn8nクローン、単なるReact Flowノードエディタではない。

## 2. 解く問題

- AI作業がチャットごとに散らばる
- 手順、判断、成果物、ログが残らない
- どのAIが何を担当したか分からない
- 外部接続やCredentialが危険になりやすい
- 成功した作業パターンを再利用できない
- 失敗・詰まり・コスト・遅延が見えない

## 3. 必須価値

```text
安全に使えること
見えること
再利用できること
```

## 4. 主要ユーザー操作

- 部品を選ぶ
- ノードを配置する
- ポートを接続する
- ノード設定を編集する
- ワークフローを保存・復元する
- ローカルモック実行する
- 実行ログとメトリクスを見る
- 失敗をRetry / Error Routeへ流す
- 成果物を確認・承認する
- 成功した流れをテンプレート化する

## 5. 完全版要件

- 型付き接続
- Workflow JSON
- 実行エンジン
- Run Log / Node Log / Audit Log
- Token / Cost / Latency / Bottleneck メーター
- Cognitive HUD
- Safety Gate
- Human Approval
- Adapter境界
- Credential安全境界
- Template / Recipe / Knowledge化
- Local-first保存

## 6. 非要件 / 禁止

- Credential値をlocalStorageに保存しない
- 外部APIをUIから直結しない
- MVP都合で長期Goalを縮小しない
- Planなしに大規模実装しない
