# Agent Workflow Studio QA Acceptance Criteria

## Definition of Done

Each phase should include:

- current state review
- plan
- implementation
- build
- lint
- typecheck
- browser QA
- save and load QA
- execution QA
- project state update
- change summary
- next plan proposal

## Safety Gates

- type check gate
- spec check
- credential boundary check
- git operation guard
- publish approval gate
- delete confirmation gate
- shell command review gate
- loop limit
- cost limit

## Credential Policy

Credential values are not normal application data.
They must not be stored in workflow JSON, templates, run logs, metrics, or browser storage.

## Browser QA Minimum

- app starts
- initial workflow is visible
- node selection works
- inspector is visible
- run all works
- queue, logs, metrics are visible
- agent and storage tabs are visible
- save and restore still work

## Completion Report

Report:

- implemented changes
- changed files
- build / lint / typecheck result
- browser QA result
- save and load QA result
- unresolved risks
- next recommended plan
