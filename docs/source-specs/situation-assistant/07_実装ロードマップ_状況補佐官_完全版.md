## Phase SA-1: text briefing MVP（最小出力チャネル）

**前提**: PR #20 がマージ済み、新ブランチを作成

### 位置づけ

- 状況補佐官の最終定義ではなく、状況説明生成レイヤーの**最小出力チャネル**である。
- 4D テキスト出力のみを扱う。音声 / アバター / 動画 / 動的ハイライト / Timeline Narration は SA-5 以降。

### タスク

1. **型定義**
   - `src/domain/briefing.ts` を作成
   - `BriefingResult`, `BriefingState`, `BriefingInput`, `BriefingInputMode` を定義

2. **入力収集**
   - `src/domain/briefingInputCollector.ts` を作成
   - Credential 除外ロジックを実装
   - 入力サイズ制限（32,000 文字）を実装
   - Run Trace step evidence と HUD Snapshot を入力に含める

3. **プロンプト構築**
   - `src/domain/briefingPromptBuilder.ts` を作成
   - 4D プロンプトテンプレート（過去・現在・未来の時間軸を含む）を実装

4. **Mock アダプター**
   - `src/adapters/briefing/BriefingAdapter.ts` インターフェース作成
   - `src/adapters/briefing/MockBriefingAdapter.ts` 実装
   - 入力統計値（ログ数・エラー数・再試行候補数・ステップ証跡件数）を反映した動的 mock を実装

5. **React Hook**
   - `src/hooks/useBriefingGenerator.ts` を作成
   - 生成フロー（idle → generating → done / error）を管理

6. **UI コンポーネント**
   - `src/components/BriefingPanel.tsx` を作成
   - `BottomMonitor.tsx` にタブを追加（`Briefing` タブ）
   - `AppShell.tsx` に必要な props 追加

7. **検証**
   - typecheck / build / lint パス
   - Browser QA（06 仕様の BQA-01〜10 を確認）

### 成果物

- BottomMonitor に「ブリーフィング」タブが追加される
- Run 後にボタン 1 つで mock ブリーフィングが生成される
- mock バナーが常時表示される
- 既存機能に回帰がない
- このタブが「最小出力チャネル」であることが UI / docs から読み取れる

## Phase SA-5: サブ機能展開

**前提**: SA-2 完了

状況説明生成レイヤーのサブ機能を分離実装する。

### タスク

1. `Timeline Extractor` を実装し、Run Log / Trace から重要イベント列を抽出する
2. `Situation Summarizer` を実装し、Metrics / Logs / Errors から要約を生成する
3. `Cause Analyzer` を実装し、Error / Trace / Diff から原因候補を生成する
4. `Future Risk Predictor` を実装し、現在状態 / 過去失敗から未来リスクを推定する
5. `Briefing Script Writer` を実装し、要約 / 原因 / 次アクションから**解説台本**を生成する
6. ノードカテゴリ「説明・ブリーフィング」を追加し、上記をノードとして利用可能にする
7. Timeline Narration / Incident Replay の UI を追加する
