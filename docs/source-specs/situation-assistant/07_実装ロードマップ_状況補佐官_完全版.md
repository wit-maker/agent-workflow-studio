## Phase SA-1: text briefing MVP

**前提**: PR #20 がマージ済み、新ブランチを作成

### タスク

1. **型定義**
   - `src/domain/briefing.ts` を作成
   - `BriefingResult`, `BriefingState`, `BriefingInput`, `BriefingInputMode` を定義

2. **入力収集**
   - `src/domain/briefingInputCollector.ts` を作成
   - Credential 除外ロジックを実装
   - 入力サイズ制限（32,000 文字）を実装

3. **プロンプト構築**
   - `src/domain/briefingPromptBuilder.ts` を作成
   - 4D プロンプトテンプレートを実装

4. **Mock アダプター**
   - `src/adapters/briefing/BriefingAdapter.ts` インターフェース作成
   - `src/adapters/briefing/MockBriefingAdapter.ts` 実装
   - 入力統計値（ログ数・エラー数・再試行候補数）を反映した動的 mock を実装

5. **React Hook**
   - `src/hooks/useBriefingGenerator.ts` を作成
   - 生成フロー（idle → generating → done / error）を管理

6. **UI コンポーネント**
   - `src/components/BriefingPanel.tsx` を作成
   - `BottomMonitor.tsx` にタブを追加（`Briefing` タブ）
   - `AppShell.tsx` に必要な props 追加

7. **検証**
   - typecheck / build / lint パス
   - Browser QA（06 仕様の BQA-01〜10 を確認）

### 成果物

- BottomMonitor に「ブリーフィング」タブが追加される
- Run 後にボタン 1 つで mock ブリーフィングが生成される
- mock バナーが常時表示される
- 既存機能に回帰がない
