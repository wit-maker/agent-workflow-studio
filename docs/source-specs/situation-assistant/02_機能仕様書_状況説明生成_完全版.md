# 機能仕様書 — 状況説明生成（完全版）

Last updated: 2026-05-25

---

## 1. 概要

状況説明生成は、Agent Workflow Studio の実行状態データを入力として **4D ブリーフィングテキスト** を生成する機能である。
本仕様は入力データの収集、プロンプト構築、生成、表示の各ステップを定義する。

---

## 2. 入力データ仕様

### 2.1 入力ソース一覧

| ソース | 型 | 収集タイミング |
|---|---|---|
| Run Log | `RunLog[]` | 最新 Run 完了後 |
| Metrics | `WorkflowMetrics` | 最新 Run 完了後 |
| ExecutionGraph | `ExecutionGraph \| null` | 最新 Run 完了後 |
| ConnectorJob 一覧 | `ConnectorJob[]` | 現在の queue 状態 |
| Workflow 構造 | `Workflow` | 現在の状態 |

### 2.2 入力フィルタリング

- Credential 値・APIキー・パスワードを含む可能性のあるフィールドは除外する。
- `node.config` 内の自由記述フィールドは除外する（将来設定で切り替え可能）。
- 最大入力トークン数を超える場合は最新エントリを優先して切り詰める。

---

## 3. 4D ブリーフィング構造

```
## What（何が起きているか）
現在のワークフロー状態・実行結果のサマリー。

## Why（なぜこの状態か）
エラー・警告の根拠となるログ・接続状態の解釈。

## How（どう対処するか）
再試行・Human Review・修正候補などの推奨アクション。

## Next（次のステップ）
ユーザーが取るべき最優先アクション 1〜3 件。
```

### 3.1 重要度バッジ

各セクションに重要度を付与する:

| バッジ | 条件 |
|---|---|
| `info` | 正常完了、情報のみ |
| `warn` | 警告あり、要確認 |
| `error` | エラー・失敗あり、要対処 |

## 4. 生成フロー

```
[ユーザー操作: 生成ボタン押下]
        ↓
[入力収集: Log / Metrics / Graph / Jobs]
        ↓
[フィルタリング: Credential除外]
        ↓
[プロンプト構築]
        ↓
[AI 呼び出し / mock 返却]
        ↓
[レスポンス検証: 長さ・構造チェック]
        ↓
[HUD パネルへ表示]
```

---

## 5. プロンプト仕様

### 5.1 システムプロンプト（概要）

```text
あなたはAIワークフローの状況を分析し、ユーザーに簡潔な日本語ブリーフィングを提供します。
入力は Agent Workflow Studio の実行ログ・メトリクス・実行グラフです。
出力は What / Why / How / Next の 4 セクションで構成してください。
各セクションは 100 字以内。Credential・APIキー・個人情報には言及しない。
```

### 5.2 入力テンプレート

```text
# ワークフロー状態

ワークフロー名: {workflow.name}
実行モード: {executionMode}
最終ステータス: {overallStatus}

## 実行ログ（最新 {N} 件）
{logs}

## メトリクス
{metrics}

## エラー・警告
{errors}

## 再試行候補
{retryCandidates}
```

## 6. mock ブリーフィング仕様

実 API 未接続時は以下の固定テキストを返す:

```text
## What
{N} ノードが実行されました。{successCount} 件成功、{errorCount} 件エラーです。

## Why
{topError または「エラーなし」}

## How
{retryCandidates がある場合: 「再試行候補があります。再試行ボタンで再実行できます。」}
{retryCandidates がない場合: 「特別な対処は不要です。」}

## Next
{nextAction: 最優先アクション}

---
⚠ これは mock ブリーフィングです。実 AI API は未接続です。
```

## 7. 表示仕様

### 7.1 BottomMonitor タブ

- タブ名: `ブリーフィング` または `状況`（既存タブの後ろに追加）
- タブは MVP で追加。既存タブ（ログ / メトリクス / キュー / 出力 / 実行グラフ / 評価 / エージェント / ストレージ / Roadmap）に干渉しない。

### 7.2 表示要素

```
[生成ボタン]  [入力ソース選択: 全ログ / 最新のみ / エラーのみ]

─────────────────────────────
📋 ブリーフィング  [info/warn/error バッジ]  生成日時

## What
...

## Why
...

## How
...

## Next
...
─────────────────────────────
⚠ mock モード（実 API 未接続）  ← 実 API 未接続時のみ表示
```

### 7.3 生成中表示

- スピナー + 「生成中...」テキスト
- キャンセルボタン

### 7.4 エラー表示

- 生成失敗時: `ブリーフィング生成に失敗しました: {error}` を赤バナーで表示
- タイムアウト時: `タイムアウトしました。入力データを減らして再試行してください。`

## 8. 状態管理

```typescript
type BriefingState = {
  status: 'idle' | 'generating' | 'done' | 'error'
  brief: BriefingResult | null
  error: string | null
  generatedAt: string | null  // ISO date string
  inputMode: 'all' | 'latest-run' | 'errors-only'
}

type BriefingResult = {
  what: string
  why: string
  how: string
  next: string
  severity: 'info' | 'warn' | 'error'
  isMock: boolean
}
```

状態は React state として保持する。localStorage への永続化は MVP スコープ外。
