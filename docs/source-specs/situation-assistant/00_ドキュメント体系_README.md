# 状況補佐官 Source Specs README

このディレクトリは、Agent Workflow Studio の**追加レイヤー**である「状況補佐官 / 状況説明生成 / 4Dワークフロー・ブリーフィング」の参照仕様を保存する場所である。

## 位置づけ

- 本仕様は `docs/source-specs/` 配下の Agent Workflow Studio 本体仕様（01〜07）を**上書きしない**。
- 状況補佐官は、本体仕様のランタイム出力（Run Log / Metrics / HUD Signal）を入力として受け取り、**テキストブリーフィングを生成する追加サービス**として設計する。
- 実装は PR #20 には混ぜない。最初の対象は音声・動画・アバターではなく、**text briefing MVP** である。

## MVP スコープ（最初の実装対象）

```text
Run Log / Metrics / HUD Signal → text briefing 生成 → HUD パネルに表示
```

音声・動画・アバター・リアルタイムストリームは MVP スコープ外。
