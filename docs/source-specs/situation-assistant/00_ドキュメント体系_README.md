# 状況補佐官 Source Specs README

このディレクトリは、Agent Workflow Studio の**追加レイヤー**である「状況補佐官 / 状況説明生成 / 4D ワークフロー・ブリーフィング」の参照仕様を保存する場所である。

---

## 概念修正の補助 SoT

`docs/project/concept-layer-correction.md`（Issue #31）を、本ディレクトリ全文書の補助 Source of Truth として扱う。文書を読むときは必ず以下の概念定義を維持する。

- **状況説明生成レイヤー**: ワークフロー状態を**過去・現在・未来の時間軸**で説明する後段レイヤー。
- **状況補佐官**: 状況説明生成レイヤーを**人間向けの役割として表現したもの**。ブリーフィングタブ / TTS / アバター / 動画生成のいずれか単独ではない。
- **text briefing MVP**: 状況補佐官の全体ではなく、状況説明生成レイヤーの**最小出力チャネルの 1 つ**。
- **4D ブリーフィング（What / Why / How / Next）**: 出力チャネルの 1 つ。音声 / アバター / 動画 / 次アクションと並ぶ並列のチャネル。
- **音声・アバター・動画**: MVP スコープ外だが、当初発想（自動ニュース動画生成の要領で状況を解説する）として削除・縮小しない応用先。

正しい変換パイプライン:

```text
ワークフロー実行状態
  → 観測
    → 認知HUDによる注意配分
      → 状況説明生成              ← 本ディレクトリの対象
        → テキスト / 音声 / アバター / 動画 / 次アクション
```

---

## 位置づけ

- 本仕様は `docs/source-specs/` 配下の Agent Workflow Studio 本体仕様（01〜07）を**上書きしない**。
- 状況補佐官は、本体仕様のランタイム出力（Run Log / Metrics / HUD Signal / Run Trace / 成果物 / 履歴）を入力として受け取り、人間向けの**状況説明**を生成する追加サービスとして設計する。
- 状況補佐官は計画作成 AI / 上位管理者 / 指示役ではない。状況説明生成レイヤーの人間向け役割表現である。
- 状況補佐官は、**過去に何が起きたか / 現在どこで止まっているか / 未来に何が起きそうか / なぜこうなったか / 次に誰が何を判断すべきか** を扱う。

## 現在の MVP スコープ（最小出力チャネル）

```text
Run Log / Metrics / HUD Signal / Run Trace step evidence
  → text 4D briefing 生成
    → BottomMonitor ブリーフィングタブに表示
```

これは状況補佐官全体ではなく、状況説明生成レイヤーの**最小出力チャネル**である。

---

## 本来仕様で必要な出力チャネル（MVP スコープ外、概念削除禁止）

```text
Situation Summary       現在状況の短い要約
Situation Detail        詳細な状況説明
Timeline Narration      過去→現在→未来の時系列説明
Incident Replay         失敗 / 詰まり / 承認待ちの再生
Workflow News Video     ワークフロー状態のニュース風動画
Avatar Briefing         アバターによる状況説明
Audio Alert Briefing    音声による重要変化の通知
Visual Explanation Render  ノード / エッジ / ログ / メーターの動的ハイライト
Next Action Briefing    人間が次に見るべき場所 / 判断すべきこと
```

音声・動画・アバターは現時点では未実装だが、**当初発想の重要な応用先**として削除・縮小せず、本ディレクトリ全文書で出力チャネルとして扱う。
