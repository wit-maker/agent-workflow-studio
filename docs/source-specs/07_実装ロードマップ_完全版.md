# Agent Workflow Studio 実装ロードマップ 完全版

## 1. 方針

このロードマップは、MVPで仕様を小さくするための文書ではない。完全版の到達点を固定した上で、実装順序を段階化するための計画である。

実装原則:

1. 先にデータモデルを固める。
2. 次にキャンバス、ノード、エッジを成立させる。
3. その後に実行、ログ、観測を接続する。
4. 認知HUDは後付け装飾ではなく、状態モデルと同時に設計する。
5. 外部連携はAdapter化し、最初はMockでもよい。
6. 安全ゲートと記録は初期から入れる。
