# Agent Workflow Studio AIエージェント運用設計書 完全版

## 1. 役割で分ける

AIエージェントはモデル名だけで分けない。以下で分ける。

- 責任範囲
- 判断レベル
- Git権限
- 成果物
- 失敗時影響範囲

## 2. 代表ロール

| ロール | 役割 |
|---|---|
| Research Agent | 外部情報収集、X/Web調査、出典整理 |
| Planner Agent | Goal分解、Plan作成、作業順序化 |
| Lead Agent | 最終判断、リスク判断、優先順位 |
| Sub Lead Agent | タスク分解、PRレビュー、統合判断 |
| Coder Agent | 実装、修正、テスト |
| Designer Agent | UI/UX、情報設計、認知負荷 |
| QA Agent | 仕様照合、回帰確認 |
| Security Agent | Credential、外部送信、危険操作確認 |
| Recorder Agent | PROJECT_STATE、Decision Log、変更履歴 |

## 3. Codex / Claude Code

| 用途 | 主担当 |
|---|---|
| 継続実装 | Codex |
| Plan作成 | Claude Code plan mode / Codex plan-first |
| 複雑レビュー | Claude Code / Codex |
| Source of Truth固定 | AGENTS.md + docs/project |

## 4. モデル確認ゲート

推奨:

```text
GPT-5.5 xhigh
```

許容:

```text
GPT-5.5 high
```

確認優先順位:

```text
1. ユーザー明示情報
2. CLI /status
3. CLI /model
4. 設定ファイル
5. 起動オプション
6. 環境変数
```

## 5. 禁止

- モデル不明のまま開始
- main / develop直接push
- git add .
- Credential保存
- Plan承認前の大規模実装
- PROJECT_STATE未更新で終了
