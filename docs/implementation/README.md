# Implementation Notes

This directory keeps implementation design notes, historical phase notes, and detail backlogs.

It is not the current plan selector.

Use `docs/project/ACTIVE_PLAN.md` first when deciding the next implementation slice. Use files in this directory only as supporting detail for the selected track.

## Current Roles

| File type | Role |
|---|---|
| `*_MVP.md` | Historical MVP design notes and implemented-slice context. |
| `runtime-audit-next-phase.md` | Runtime Audit detail backlog, subordinate to `docs/project/ACTIVE_PLAN.md`. |
| `runtime-audit-integration-plan.md` | Historical worktree integration plan for the landed Runtime Audit phase. |
| `SCREEN_SPEC_ALIGNMENT.md` | Screen/spec mapping reference. |

Do not add a new current-plan file here. If next-slice order changes, update `docs/project/ACTIVE_PLAN.md`.
