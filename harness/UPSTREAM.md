# Upstream provenance

This Codex-specific integration is adapted from
`wit-maker/fable5-harness` at commit
`62f4882dcea83c24522db92959b17a5b46b90486`.

Retained ideas:

- Markdown state as a durable source of truth;
- task, handoff, evidence, and review records;
- worktree isolation;
- evidence anchored to Git state;
- independent review before completion;
- secret-like value sanitization.

Changed for this repository:

- Claude-versus-Codex routing became GPT-5.6 Sol/Terra/Luna responsibility
  routing;
- Codex project agents use `.codex/agents/*.toml`;
- the reusable entrypoint is a repo skill under `.agents/skills/`;
- branch names follow the repository's required `codex/` prefix;
- Terra owns project management and review; Luna owns implementation only;
- volatile logs remain untracked and canonical state is regenerated by Terra.

No upstream dependency or runtime package is added. The integrated CLI uses
only the Python standard library.
